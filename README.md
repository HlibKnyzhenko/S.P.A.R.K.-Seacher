# S.P.A.R.K. Searcher

Интерактивный поиск университетов США для international first-year applicants. Сайт сопоставляет академический профиль абитуриента с каталогом вузов и помогает собрать осмысленный список для поступления.

## Что умеет

- Подбирает университеты по специальности, штату, GPA, SAT, IELTS, DET, бюджету и формату кампуса.
- Показывает условную категорию поступления: `Запасной`, `Реалистично` или `Цель`.
- Учитывает тип финансовой помощи: `need-based`, `merit`, `100% demonstrated need` и специальные full-cost программы.
- Поддерживает фильтры `need-blind`, `need-aware`, ограниченные scholarships и отсутствие institutional need-based aid.
- Содержит 70 университетов и колледжей США с официальными ссылками на условия финансовой помощи.
- Адаптирован для телефонов, поддерживает светлую и действительно тёмную тему.
- Считает посетителей, визиты и поиски через Supabase с ограничением повторных действий с одного устройства.

## Запуск

Это статический сайт, поэтому достаточно открыть `index.html` в браузере. Для разработки можно использовать любой локальный static server.

## Supabase: счётчики

1. Создайте проект в Supabase.
2. В Supabase Dashboard откройте `SQL Editor` и выполните содержимое [supabase-schema.sql](supabase-schema.sql).
3. Укажите URL проекта и publishable key в [supabase-config.js](supabase-config.js).

В браузере используется только publishable key. Не добавляйте в репозиторий `service_role` key: он предназначен только для защищённого backend-кода.

Счётчики работают так:

- `Посетители` - уникальные браузеры с сохранённым локальным идентификатором.
- `Визиты` - не чаще одного раза в 12 часов с одного устройства.
- `Поиски` - не чаще одного раза в минуту с одного устройства.

Таблицы закрыты через RLS. Сайт может вызывать только RPC-функции для чтения агрегированных цифр и регистрации событий.

## Деплой на Vercel

1. Импортируйте GitHub-репозиторий в Vercel.
2. В `Root Directory` выберите `SearchUniversities`.
3. Укажите `Framework Preset: Other`.
4. Оставьте `Build Command` пустым и нажмите Deploy.

После публикации откройте сайт и сделайте поиск: Supabase начнёт собирать общую статистику.

## Стек

HTML, CSS, JavaScript, Supabase и Lucide Icons.

## Важно

Результаты поиска помогают сформировать список вузов, но не являются гарантией поступления или финансовой помощи. Перед подачей заявки всегда проверяйте актуальные требования и условия финансирования по официальной ссылке в карточке университета.
